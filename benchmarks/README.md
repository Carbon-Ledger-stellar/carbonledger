# Benchmark data

See `docs/benchmarking.md` for the full methodology.

- `baseline.json` — the committed baseline `compare_benchmarks.py` compares
  every PR against. **Does not exist yet in this initial setup** — no
  fabricated numbers are checked in here. Bootstrap it once, right after
  this PR merges to `main`, by running:

  ```bash
  python3 scripts/compare_benchmarks.py --run
  cp benchmarks/current.json benchmarks/baseline.json
  ```

  and committing `benchmarks/baseline.json` directly to `main` (or via a
  trivial PR). Until that happens, `compare_benchmarks.py` treats a missing
  baseline as "nothing to compare" and passes — see the script's
  `load_json`/`main` handling — so CI won't false-fail in the meantime, but
  it also isn't gating anything yet.

- `current.json` — generated by CI on every run (not committed); the
  latest snapshot, uploaded as a build artifact.

- `history.csv` — the committed historical trend file. Starts as a header
  row only; append a row every time `baseline.json` is intentionally
  updated (see "Updating the baseline" in `docs/benchmarking.md`).
